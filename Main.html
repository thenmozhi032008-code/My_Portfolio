Secure Login System

Secure Login System is a Python-based authentication application that allows users to register and log in securely. It protects user credentials by storing passwords in hashed form instead of plain text, validates user input, and securely manages user authentication using an SQLite database. The system also uses parameterized SQL queries to help prevent SQL injection attacks, ensuring that only authorized users can access the application.
